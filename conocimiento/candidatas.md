# Lecciones candidatas

Bandeja de lecciones de este proyecto que podrían servir en otros. Se registran acá y **solo acá**: el motor no lleva lecciones de un proyecto a otro. Una persona decide si alguna asciende.

## Formato

```
## <título>

**Fecha:** <fecha> · **Lección:** L-<número> en lecciones.md · **Estado:** candidata | ascendida | descartada

**Por qué podría servir fuera:** <qué tiene de general, sin datos de este proyecto>
```
