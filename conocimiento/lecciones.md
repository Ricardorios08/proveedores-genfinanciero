# Lecciones

Lo aprendido en este proyecto, con la situación que lo enseñó. Las escribe `/archivar` cuando una unidad deja una, o una persona.

## Formato

```
## L-<número> — <título>

**Fecha:** <fecha> · **Unidad:** <unidad de origen>

**Qué pasó:** <la situación, en hechos>
**Qué se aprendió:** <la lección, en una frase>
**Qué cambia:** <qué se hace distinto a partir de ahora; si se volvió decisión, cuál>
```

Si la lección podría servir fuera de este proyecto, se registra además en `candidatas.md`.
