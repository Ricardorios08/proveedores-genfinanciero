# Patrones

Formas de hacer que se repiten en este proyecto y conviene seguir. Las escribe `/archivar` cuando una unidad deja una, o una persona.

## Formato

```
## <nombre del patrón>

**Fecha:** <fecha> · **Unidad:** <unidad de origen>

**Cuándo:** <la situación en que aplica>
**Cómo:** <qué se hace, con un ejemplo en el proyecto: archivo con línea>
**Cuándo no:** <la situación parecida en que no aplica>
```
