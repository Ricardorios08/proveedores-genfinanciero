# Mapa del sistema

Cómo es el sistema hoy. Una página por parte del sistema, en esta carpeta. Lo actualiza `/archivar` cuando una unidad cambia cómo es el sistema.

## Formato de una página

```
# <parte del sistema>

**Última revisión:** <fecha> · **Unidad:** <unidad que la tocó por última vez>

## Qué es

## Cómo se relaciona con el resto

## Afirmaciones

| Afirmación | Estado | Evidencia |
|---|---|---|
| <algo que es cierto del sistema> | verificado | <archivo con línea, o comando y resultado> |
| <algo que se cree pero no se comprobó> | sospechado | <por qué se cree; cómo se verificaría> |
```

## Reglas

- Cada afirmación lleva su **estado epistémico**: **verificado** (se comprobó en el trabajo real) o **sospechado** (se cree, no se comprobó).
- Lo sospechado no se usa como base de una decisión sin verificarlo antes.
- Una afirmación que deja de ser cierta se corrige, no se tacha: el historial guarda la anterior.
